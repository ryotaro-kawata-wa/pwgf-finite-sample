# Code license scope

The author approved the MIT License for the project-authored Lean formalization,
verification scripts and numerical experiment code on 2026-10-06.

The public bundle places a copy of the MIT License in the `lean/`, `experiments/`
and `scripts/` code directories. This code license does not grant a new license
for the manuscript, bibliography entries, cited papers, external dependency
sources or third-party figures. Dependencies retain their own licenses and are
retrieved at the recorded revisions rather than vendored into the bundle.

The manuscript's arXiv distribution license is a separate submission choice.
